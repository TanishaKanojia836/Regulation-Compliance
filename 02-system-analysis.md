# 02 - System Analysis

## 1. System Name

College Library Management System

## 2. Purpose

The system is used to manage:

- Student library accounts
- Book borrowing
- Book returns
- Book reservations
- Fines
- Library notifications

## 3. Users

The main users are:

- Students
- Librarians
- College administrators
- IT administrators

## 4. Personal Data Processed

The system may process:

- Student name
- Student ID
- Email address
- Phone number
- Login information
- Borrowing records
- Return dates
- Reservation records
- Fine information
- Security logs

## 5. Data Processing Activities

| Activity | Personal Data |
|---|---|
| Student registration | Name, ID, email |
| Login | Account credentials |
| Book borrowing | Student ID, book details, date |
| Book reservation | Student ID, reservation details |
| Notifications | Name, email |
| Fine management | Student ID, fine details |
| Security monitoring | Login/activity information |

## 6. Compliance Question

For every processing activity, the college should determine:

- What data is being processed?
- Why is it being processed?
- What is the applicable legal basis?
- Who can access it?
- How long should it be retained?
- What happens when the data is no longer required?

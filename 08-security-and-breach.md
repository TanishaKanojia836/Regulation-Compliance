# 08 - Security and Breach Management

## 1. Security Controls

The library system should use appropriate technical and organizational safeguards.

### Technical Controls

- Encryption
- HTTPS
- Strong authentication
- Multi-factor authentication where appropriate
- Role-based access control
- Security logging
- Regular updates
- Backup and recovery

### Organizational Controls

- Employee training
- Access reviews
- Security policies
- Vendor reviews
- Incident-response procedures

---

## 2. Example Breach

### Scenario

An attacker gains unauthorized access to the library database.

### Potentially affected information

- Student names
- Student IDs
- Email addresses
- Borrowing records

### Response

1. Detect the incident.
2. Contain the incident.
3. Investigate what happened.
4. Identify affected data.
5. Document the incident.
6. Follow applicable notification requirements.
7. Correct the security weakness.
8. Review the incident and improve controls.

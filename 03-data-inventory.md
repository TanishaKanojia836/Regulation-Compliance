# 03 - Data Inventory

| Data | Purpose | Source | Access |
|---|---|---|---|
| Student Name | Identification | Student | Student/Librarian |
| Student ID | Account management | College/Student | Student/Librarian |
| Email | Notifications | Student/College | Authorized staff |
| Phone Number | Communication | Student | Authorized staff |
| Borrowing History | Library management | System | Student/Librarian |
| Reservation History | Book reservations | System | Student/Librarian |
| Fine Information | Fine management | System | Student/Librarian |
| Login Information | Authentication | Student/System | Authorized IT |
| Security Logs | Security | System | Authorized IT |

## Data Minimization Review

The college should check whether each data element is necessary for the specified purpose.

For example, continuous GPS location is not normally necessary for ordinary library borrowing services.

Therefore, the system should avoid collecting unnecessary location information.

## Finding

The system should maintain a documented inventory of personal data and the purposes for which each category is processed.

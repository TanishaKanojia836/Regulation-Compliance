## 1. Aim

To study the requirements of India's Digital Personal Data Protection Act, 2023 and the Digital Personal Data Protection Rules, 2025, identify the requirements applicable to a College Library Management System, and develop a practical compliance plan.

---

## 2. Regulation Selected

The regulation selected for this project is:

**Digital Personal Data Protection Act, 2023 (DPDP Act)**

The assessment also considers the:

**Digital Personal Data Protection Rules, 2025**

The Act establishes a framework for processing digital personal data while recognizing individuals' rights and the need for lawful processing. The Rules provide detailed implementation requirements. 

---

## 3. System Selected

The system assessed in this project is a College Library Management System.

The system allows students to:

- Log in.
- Search for books.
- Borrow and return books.
- Reserve books.
- View borrowing history.
- Receive notifications.

---

## 4. Compliance Objectives

The objectives are:

- Identify personal data processed by the system.
- Identify applicable regulatory requirements.
- Compare the current system with those requirements.
- Identify compliance gaps.
- Develop corrective measures.
- Create an implementation plan.
- Establish a process for monitoring compliance.

---

## 5. Main Compliance Areas

The assessment covers:

- Notice and transparency
- Consent where applicable
- Data principal rights
- Data security
- Data retention and erasure
- Grievance redressal
- Third-party/vendor management
- Personal data breach response
- Record keeping and compliance monitoring

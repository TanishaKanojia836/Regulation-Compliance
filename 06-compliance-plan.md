# 06 - Compliance Plan

## 1. Privacy Notice

### Action

Create a clear privacy notice for students.

### Contents

The notice should explain:

- Personal data collected.
- Purpose of processing.
- Relevant rights.
- How to contact the college.
- How to raise a grievance.

### Responsible Team

College Administration + IT

---

## 2. Data Inventory

### Action

Create and maintain an inventory of personal data.

### Responsible Team

IT + Library

---

## 3. Rights Request Process

### Action

Create a process for receiving and handling applicable student requests.

### Responsible Team

Administration + IT

---

## 4. Retention Policy

### Action

Define how long different categories of personal data should be retained and when they should be deleted or otherwise disposed of.

### Responsible Team

Administration + IT + Library

---

## 5. Security

### Action

Implement appropriate security measures.

Examples:

- Encryption
- Access control
- Strong authentication
- Security monitoring
- Regular updates
- Backup procedures

### Responsible Team

IT Department

---

## 6. Vendor Management

### Action

Review contracts and controls for third parties that process student information.

### Responsible Team

Administration + IT

---

## 7. Breach Management

### Action

Create a documented personal-data breach response procedure.

### Responsible Team

IT + Administration

---

## 8. Training

### Action

Train librarians, administrators, and relevant employees on data protection responsibilities.

### Responsible Team

Administration
